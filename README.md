# my-first-site

אתר אישי של אופק שליט, מקעקעת ואמנית. באתר יש היכרות קצרה, רקע אישי, הקעקועים שלי ודרכים ליצירת קשר.

האתר דו-לשוני, בעברית ובאנגלית. כפתור בפינה העליונה של העמוד מחליף בין השפות: בעברית העמוד מוצג מימין לשמאל, ובאנגלית משמאל לימין.

האתר בנוי מקובצי HTML, CSS ו-JavaScript בלבד.

## איך פותחים את האתר

פותחים את הקובץ `index.html` בדפדפן, למשל בלחיצה כפולה עליו.
